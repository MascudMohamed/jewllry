# Jewelix Website (School Project)

A static recreation of the [Jewelix](https://jewelix.framer.website/) jewellery e-commerce landing page using HTML, CSS, and JavaScript.

## Folder structure

```
jewelix-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/          (optional local images)
```

## How to open

Open `index.html` in your browser (double-click, or use Live Server in VS Code / Cursor).

Images load from external CDNs (Framer + Unsplash), so you need an internet connection.

## Features

- Sticky header with desktop nav + mobile menu
- Hero with split typography
- Collection promo cards
- Feature grid
- Product filter (All / Ring / Earring / Watch)
- Newsletter form
- Blog & footer sections

The Framer “See More Templates” / “Customization Service” floating buttons are **not** included.
